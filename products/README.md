# products/

This directory contains the Quarto source files used to generate the manuscript and supplementary materials.

The manuscript presents the primary research question, statistical methods, and main findings. The supplement provides additional methodological details, descriptive analyses, complete regression results, and sensitivity analyses.

Tables and figures are generated by the R analysis pipeline and incorporated into the documents during rendering.

The manuscript and supplement can be rendered using Quarto after the required analysis outputs have been generated.
