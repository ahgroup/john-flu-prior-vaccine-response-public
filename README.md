# Associations between prior influenza vaccine type and subsequent vaccine-induced antibody responses

This repository contains the data, code, and analysis outputs associated with the manuscript "Associations between prior influenza vaccine type and subsequent vaccine-induced antibody responses."

Paper: [insert link when available].

The study investigates associations between prior-season influenza vaccine formulation and subsequent hemagglutination inhibition (HAI) antibody responses using data from the FluVac cohort and the University of Rochester influenza vaccine clinical trial (URIV).

## Repository structure

-   `assets/` contains static figures or graphical elements not generated by code.

-   `data/` contains the datasets used in the analysis. These are the input data files read by the pipeline.

-   `logs/` contains log files produced by parallel workers during pipeline execution. It is useful for debugging and monitoring model fitting.

-   `products/` contains .qmd and compiled .docx manuscript and supplementary materials.

-   `R/` contains all R source files used in the analysis. These files define data processing, model fitting, posterior prediction, derivation of measures, and figure/table generation functions called by the pipeline.

-   `renv/` is automatically generated by the {renv} package. It stores the project-specific R library and ensures package version reproducibility. The renv.lock file records exact package versions used for the analysis.

-   `results/` contains figures and tables generated by the pipeline that appear in the manuscript and supplementary materials.

-   `_targets.R` is the main pipeline definition file. It specifies the full reproducible workflow, including data processing, Bayesian model fitting, posterior prediction, sensitivity analyses, and figure/table generation. Running targets::tar_make() executes this pipeline in full. \_targets/ is automatically generated by the {targets} package. It stores intermediate objects, metadata, and dependency information required for reproducible pipeline execution. This directory should not be modified manually.

## Reproducibility Instructions

To reproduce our results, first clone or download this GitHub repository. Once downloaded, open the `.Rproj` file in Rstudio. We used the R package `targets` to implement the analysis pipeline which can be executed in full by running: `targets::tar_make()`. The pipeline automatically detects the number of cores on your device and runs in parallel, leaving two cores free. If you are in a limited computing environment, you can run sequentially by specifying `use_crew = FALSE`. You can visualize the workflow using `targets::tar_visnetwork(TRUE)` and run only selected targets by passing a vector of target names to `tar_make()` optionally using tidyselect helpers. Due to OS and file system differences, some targets may appear outdated even if they are up-to-date.

One you have cloned our repository, follow these instructions to reproduce our results.

1.  Open the `john-flu-prior-vaccine-response-public.Rproj` file in Rstudio.

2.  Once renv initializes, run the command renv::restore() in the console to begin installing the required packages. If you have issues at this stage you can also install the dependencies manually, but if you do not use renv or you use different package versions than we did, our code might not work for you.

3.  Now you can run our pipeline by running `targets::tar_make()` in the console. See the `_targets.R` file for further instructions and the full targets pipeline. If you are new to targets and want to learn more about how the pipeline works, we recommend reading the targets manual which can be found here: <https://books.ropensci.org/targets/>.
